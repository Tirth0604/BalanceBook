# BalanceBook — MongoDB Schema

All monetary fields are **integer minor units** (`INT64-safe JS numbers ≤ 2^53`).
Field name suffix `_minor` is not used; instead the schema documents `minor` in the path,
e.g. `totalMinor`, `shareMinor`, `amountMinor`.

Conventions: `mongoose.Schema` with `{ timestamps: true }` everywhere → `createdAt` /
`updatedAt` are automatic. Reference fields are `Schema.Types.ObjectId`.

## 5. `notifications`

`userId` (indexed), `groupId?`, `type` enum (`group_invitation`, `group_joined`,

`settlement_disputed`, `budget_threshold`, `recurring_due`, `insight`), `title`, `body`,

Indexes: `{ userId, isRead, createdAt }`.

## 6. `recurringexpenses`

`groupId`, `title`, `totalMinor`, `currency`, `category`, `paidBy`, `participants`
(same shape as expense, frozen template), `frequency: 'daily'|'weekly'|'monthly'`,
`interval` (int ≥1), `startDate`, `nextDueDate` (indexed), `endDate?`,
`occurrenceCount`, `maxOccurrences?`, `isActive`, `pausedAt?`,
`lastGeneratedExpenseId?`, `createdBy`.
Duplicate prevention: unique index `{ groupId, recurrenceTemplateId, occurrenceIndex }`
on the generated-expense bookkeeping sub-document, plus an idempotent
`(recurrenceId, periodKey)` unique index on `expenses` — the scheduler can run twice
without double-charging.

## 7. `budgets`

`groupId`, `scope: 'group_total'|'category'`, `category?`, `limitMinor`, `currency`,
`alertThresholds: [75,90,100]`, `period: 'overall'|'monthly'`, `periodKey?`, `createdBy`.
Unique index `{ groupId, scope, category, periodKey }`.

## 8. `expenseauditlogs` — append-only

`expenseId`, `groupId`, `modifiedBy`, `action: 'created'|'updated'|'deleted'|'restored'`,
`previousData` (Mixed), `updatedData` (Mixed), `changeSummary` (String), `reason?`.
Index `{ expenseId, createdAt }`. **Never updated or deleted by application code.**

## 9. `refreshtokens`

`userId` (indexed), `tokenHash` (sha256, unique), `familyId` (rotation reuse detection),
`userAgent`, `ip`, `expiresAt` (TTL index), `revokedAt?`.

## 10. `invitationtokens`

`groupId`, `email?`, `code`, `tokenHash`, `createdBy`, `expiresAt` (7 days, TTL),
`acceptedAt?`, `acceptedBy?`.

## Balance derivation (why there is no `balances` collection)

```
net(member) = Σ expense.groupAmountMinor where member === paidBy
            − Σ participant.shareMinor where participant === member
            − Σ confirmed-settlement amounts received by member
            + Σ confirmed-settlement amounts paid by member
```

Receiving a repayment settles a receivable (so it reduces `net`); making a repayment
settles a debt (so it increases `net`). `net > 0` means the group still owes this member.

`Σ net(member) === 0` per group is asserted by `balanceService.assertGroupInvariant()`
after every financial write. If it ever fails, the write is rolled back and a
`500 FINANCIAL_INVARIANT_VIOLATION` is returned — this is the guard the spec asks for.
